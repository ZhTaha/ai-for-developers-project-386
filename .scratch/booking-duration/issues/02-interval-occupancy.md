# 02: Занятость интервалом + сетка 15 минут

**What to build:** бронь занимает всё время своей встречи, а не один слот. Гость, бронируя 60-минутную встречу, блокирует все пересекающиеся 15-минутные слоты; другой гость получает 409 при попытке занять любой из них, но примыкающий вплотную слот свободен. Отмена брони владельцем освобождает все её слоты. slotStart вне 15-минутной сетки отклоняется с 400. Последняя встреча дня может начаться до конца окна доступности и выйти за endTime. Слоты вычисляются по 15-минутной сетке.

**Blocked by:** 01 (Контракт: бронь с длительностью + совместимость хранилища).
