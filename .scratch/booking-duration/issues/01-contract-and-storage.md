# 01: Контракт: бронь с длительностью + совместимость хранилища

**What to build:** TypeSpec-контракт и хранилище описывают бронь с длительностью, и существующие брони продолжают работать. Владелец, открыв список броней через API, видит у каждой брони её длительность; брони, сохранённые до этой фичи (без длительности), возвращаются как 15-минутные. Контракт (TypeSpec) обновляется первым: модель Booking получает durationMinutes, slotStart описывается на 15-минутной сетке.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] API GET /api/bookings отдаёт длительность для старых и новых броней
